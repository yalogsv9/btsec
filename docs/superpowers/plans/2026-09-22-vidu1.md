# Vidu1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to execute this plan task-by-task.

**Goal:** Build a tested Spring Security 6 form-login example in the `SPRING_WS` Maven project.

**Architecture:** `SecurityConfig` owns a `SecurityFilterChain`, BCrypt encoder, and one in-memory account. `Vidu1Controller` maps three Thymeleaf views; `MockMvc` verifies public, protected, and authenticated flow.

**Tech Stack:** Java 17, Maven, Spring Boot 3.5.0, Spring Security 6, Thymeleaf, JUnit 5, MockMvc.

**Spec:** `docs/superpowers/specs/2026-09-22-vidu1-design.md`

**Files:** Create `src/test/java/vn/edu/ltweb/springws/vidu1/Vidu1SecurityIntegrationTest.java`.

**Consumes:** `SpringWsApplication`.

**Produces:** Required `/vidu1`, `/vidu1/private`, and `/login` behavior.

- [ ] Write these test expectations:


### Task 3: Implement security configuration and routing

**Files:** Create `src/main/java/vn/edu/ltweb/springws/vidu1/SecurityConfig.java` and `src/main/java/vn/edu/ltweb/springws/vidu1/Vidu1Controller.java`.

**Produces:** User `student` / `123456`, custom login at `/login`, public `/vidu1`, and authenticated `/vidu1/private`.

- [ ] Configure the filter chain:

```java
http.authorizeHttpRequests(auth -> auth
    .requestMatchers("/css/**", "/vidu1", "/login").permitAll()
    .requestMatchers("/vidu1/private").authenticated()
    .anyRequest().denyAll())
  .formLogin(form -> form.loginPage("/login")
    .defaultSuccessUrl("/vidu1/private", true).permitAll())
  .logout(logout -> logout.logoutSuccessUrl("/vidu1"));
```

- [ ] Register a `BCryptPasswordEncoder` and an `InMemoryUserDetailsManager` holding `User.withUsername("student").password(encoder.encode("123456")).roles("STUDENT")`.
- [ ] Map `GET /vidu1`, `GET /vidu1/private`, and `GET /login` to `vidu1/home`, `vidu1/private`, and `vidu1/login`.
- [ ] Run `mvn test -Dtest=Vidu1SecurityIntegrationTest`; expect template-related failure only.
