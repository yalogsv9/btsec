# Vidu3 Remember-me Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an isolated Spring Security remember-me demonstration at `/vidu3`.

**Architecture:** An order-3 security chain applies only to `/vidu3/**` and uses a dedicated in-memory account. Its form-login endpoint enables Spring Security's token-based remember-me cookie for seven days. A small controller and Thymeleaf pages expose the flow without modifying the Vidu1 or Vidu2 behavior.

**Tech Stack:** Java 17, Spring Boot 3.5.0, Spring Security 6, Thymeleaf, JUnit 5, MockMvc.

**Spec:** `docs/superpowers/specs/2026-09-23-vidu3-design.md`

## Global Constraints

- Keep Java 17, Spring Boot 3.5.0, and current dependencies.
- Do not add OAuth2, Google credentials, persistence, or a dependency for Vidu3.
- Preserve independent chains for `/vidu1/**`, `/vidu2/**`, and `/vidu3/**`.
- Use account `rememberme` / `123456`, remember-me parameter `remember-me`, and 604800-second validity.
- Make a single Vidu3 feature commit with no `Co-authored-by` trailer.

## Review Focus

- A request without a session or remember-me cookie must redirect to the Vidu3 login page.
- Login without the checkbox must not set a remember-me cookie.
- The seven-day cookie must authenticate a fresh request that has no `HttpSession`.
- Invalid credentials must redirect to the error URL and return only an expired remember-me cookie, never a usable token.
- CSRF-protected logout must expire the remember-me cookie and redirect to the logout URL.

                    .param("username", "rememberme").param("password", "123456"))
       .andExpect(authenticated().withUsername("rememberme"))
       .andExpect(redirectedUrl("/vidu3"))

@Test
void rememberMeCookieAuthenticatesRequestWithoutSession() throws Exception {
    MockCookie token = mvc.perform(post("/vidu3/login").with(csrf())
                    .param("username", "rememberme").param("password", "123456")
                    .param("remember-me", "on"))
       .andExpect(cookie().exists("remember-me")).andReturn()
       .getResponse().getCookie("remember-me");

    mvc.perform(get("/vidu3").cookie(token))
       .andExpect(authenticated().withUsername("rememberme"))
       .andExpect(content().string(containsString("rememberme")));

@Test
void csrfLogoutExpiresRememberMeCookie() throws Exception {
    MockCookie token = mvc.perform(post("/vidu3/login").with(csrf())
                    .param("username", "rememberme").param("password", "123456")
                    .param("remember-me", "on"))
       .andExpect(cookie().exists("remember-me")).andReturn()
       .getResponse().getCookie("remember-me");
    mvc.perform(post("/vidu3/logout").with(csrf()).cookie(token))
       .andExpect(redirectedUrl("/vidu3/login?logout"))

```java
@Bean @Order(3)
SecurityFilterChain vidu3FilterChain(HttpSecurity http,
        @Qualifier("vidu3UserDetailsService") UserDetailsService users,
        PasswordEncoder passwordEncoder) throws Exception {
    DaoAuthenticationProvider provider = new DaoAuthenticationProvider(users);
    provider.setPasswordEncoder(passwordEncoder);
    return http.securityMatcher("/vidu3/**")
        .authenticationProvider(provider)
        .authorizeHttpRequests(auth -> auth.requestMatchers("/vidu3/login").permitAll()
            .anyRequest().authenticated())
        .formLogin(form -> form.loginPage("/vidu3/login").loginProcessingUrl("/vidu3/login")
            .defaultSuccessUrl("/vidu3", true).failureUrl("/vidu3/login?error=true").permitAll())
        .rememberMe(remember -> remember.key("vidu3-remember-me-key")
            .rememberMeParameter("remember-me").tokenValiditySeconds(604800))
        .logout(logout -> logout.logoutUrl("/vidu3/logout")
            .logoutSuccessUrl("/vidu3/login?logout").invalidateHttpSession(true)
            .deleteCookies("JSESSIONID", "remember-me"))
        .build();
}

@GetMapping("/vidu3/login") String login() { return "vidu3/login"; }
@GetMapping("/vidu3") String home(Authentication authentication, Model model) {
    model.addAttribute("username", authentication.getName());
    return "vidu3/home";
}
```
